# Travel App Sign In Screen UI in Flutter ✈️✨

A modern **travel app sign in screen** built with Flutter, featuring a night-blue gradient with soft sparkles, a glassy credentials card, a bright **Sign in now** button and selectable **Facebook / Google / Apple** login options with a glowing outline.

The UI is split into small, reusable components, the same way you would structure a React Native app.

## ✨ Features

- 🌌 Night-blue gradient background with sparkle stars
- 🪪 Glass card with email and password fields
- 📋 Paste email from the clipboard in one tap
- 🔒 Lock icon to show / hide the password
- ✅ Email and password validation
- 🔵 Selectable social options with a glowing outline and radio dot
- 🧩 Reusable components with a barrel export (like `components/index.ts`)

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Travel-App-Sign-In-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Travel-App-Sign-In-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
